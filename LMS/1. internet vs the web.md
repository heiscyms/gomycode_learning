How Does The Internet Work ?
It's Important to note that the internet is a global network of physical cable , which can include , Copper telephone wires, TV Cable and Fibre Optic Cables

when you visit a website your computer sends in a request over these wires to a server.

A server is where websites are stored, and it works a lot like your computer's hard drive. Once the request arrives, the server retrieves the website and sends the correct data back to your computer. What's amazing is that this all happens in just a few seconds!
